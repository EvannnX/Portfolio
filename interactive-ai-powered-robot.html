Interactive AI-Powered Robot

2025

Context
Interactive Media Arts, NYU Shanghai
Built with
ESP32, Qwen API, servos, 3D-printed parts
Code
github.com/EvannnX/JARVIS ↗

The Interactive AI Robot is a plush toy with real-time voice interaction and basic motion. Most talking toys play pre-recorded lines; this one listens, answers in unscripted speech, and gestures while it talks. An ESP32 microcontroller handles the audio and calls the Qwen API to generate speech, and servo motors sync gestures (nod, wave, head turn) with what it says. The mechanical design builds on the open-source OTTO Robot platform.
